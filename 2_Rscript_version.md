# 📊 GreenDA R Script Version (v5.10)

> **Note**
> **GreenDA R Script** is designed for users who already have R installed on their computer or wish to customize the underlying source code to fit their specific research needs.

---

### ⚙️ Prerequisites
To run this version, you must have an established R development environment:
* **R & RStudio** installed.
* All required libraries and packages pre-installed.

---

### 📁 Required Folder Structure

> ⚠️ **Important Deployment Rule**
> For the application to function properly, the R script and the `www` folder **must be located in the exact same directory.**

```text
your-project-folder/
├── app.R (or ui.R / server.R)
└── www/   📂 (Must be here!)
```
