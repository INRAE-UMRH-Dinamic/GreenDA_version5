# 📊 GreenDA Practice Dataset

This folder contains a practice dataset provided exclusively for users to learn and practice running the GreenDA application.

## 🔬 Experimental Design & Data Summary
* **Animals:** Data was collected from a total of 53 suckling cows.
* **Design:** The trial was conducted using a **2x2 factorial design**, incorporating both diet factors and breed factors.
* **Details:** For comprehensive information regarding the animal trial and data collection, please refer to the relative GreenDA research paper: **[Read the Reference Paper Here](LINK WILL BE ADDED)**.

---

## 📂 File & Folder Descriptions

### 1. 📄 `GreenDA_input_GreenFeed.xlsx`
This file is the input dataset for your practice run and consists of 3 sheets:
* **ReadMe:** Contains the metadata explaining what each column in the `GF_data` and `Treat` sheets represents.
* **GF_data:** The raw data downloaded from the GreenFeed system. Use this sheet during **Step 1 (UPLOAD GREENFEED FILE)** in the application.
* **Treat:** Contains treatment information for each individual animal. Use this sheet during **Step 2 (UPLOAD TREATMENT FILE)** in the application.

### 2. 📁 `GreenDA_output/` (Folder)
This folder contains the actual analysis results processed and verified by the authors using GreenDA.
* **How to use:** Run the analysis yourself using the input file above, and then compare your output with the files in this folder to verify if your results match or to identify any discrepancies.
