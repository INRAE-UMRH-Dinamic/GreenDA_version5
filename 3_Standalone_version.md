# 💻 GreenDA Standalone Version (v5.10)

> **Note**
> **GreenDA Standalone** is a user-friendly, point-and-click desktop application designed for users who want to utilize GreenDA without any prior experience with R.

---

### 🔍 Key Features
* **No R Installation Required:** While it is based on R Shiny just like the script version, this standalone application comes pre-packaged with R and all necessary libraries. 
* **One-Click Execution:** You only need to install this single file on your computer to get started immediately.
